# Documentation sources

The user site is built with Sphinx, MyST, Doxygen and Breathe. See
[contributing-docs.md](contributing-docs.md) for local build and GitHub Pages
setup instructions. Its entry point is [index.md](index.md).
The maintenance guide includes uv commands for building and previewing on
another computer. [examples.md](examples.md) lists the C++ programs exercised
by the package-consumer test.
